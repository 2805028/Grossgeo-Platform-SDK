# GrossGeo Deep Links (`grossgeo://`) — руководство для разработчиков плагинов

**Для кого:** сторонние разработчики плагинов, желающие открывать страницы GrossGeo User Panel (покупка лицензии, карточка продукта, отзывы, пробный период) по кнопке из своего плагина.

> Требуется установленный **GrossGeo User Panel**. SDK-метод `RequestTrialAsync` (§4.1) — начиная с **GrossGeo.SDK.Stub 2.1.6**; URI-схема работает независимо от версии SDK.

---

## 1. Что это

URI-схема `grossgeo://` открывает приложение **GrossGeo User Panel** на нужной странице. Используйте её в своём плагине для кнопок вида «Купить лицензию», «Оставить отзыв», «Мои лицензии», «Попробовать бесплатно».

Схема регистрируется в Windows инсталлятором User Panel — отдельная настройка со стороны плагина не нужна. Если User Panel уже запущен (в том числе в фоне), окно просто активируется и переходит на нужную страницу; если установлен, но не запущен — запустится сразу на ней.

## 2. Формат и команды

```
grossgeo://{команда}[/{параметр}]
```

| URI | Открывает |
|-----|-----------|
| `grossgeo://purchase/{productId}` | Карточку продукта сразу в режиме **покупки** — кнопка «Купить лицензию» |
| `grossgeo://product/{productId}` | Карточку продукта (описание, версии, цены) |
| `grossgeo://reviews/{productId}` | Отзывы о продукте |
| `grossgeo://start-trial/{productId}` | Карточку продукта и запрашивает старт trial — кнопка «Попробовать бесплатно» (см. §3.1 — здесь работает и ProductKey, не только ProductId) |
| `grossgeo://licenses` | Список лицензий пользователя |
| `grossgeo://home` | Главную страницу панели |
| `grossgeo://profile` | Профиль пользователя |
| `grossgeo://team` | Страницу команды |
| `grossgeo://settings` | Настройки панели |
| `grossgeo://login` | Страницу входа |

Команда регистронезависима, завершающий `/` допустим.

## 3. Что такое `{productId}` — важно

`{productId}` — это **GUID продукта в каталоге платформы**, в обычном формате с дефисами:

```
grossgeo://purchase/3fa85f64-5717-4562-b3fc-2c963f66afa6
```

**Не перепутайте** с двумя другими идентификаторами вашего продукта:

| Идентификатор | Формат | Для чего | Подходит для deep-link? |
|---|---|---|---|
| **ProductId** | GUID | Идентификатор продукта в каталоге | ✅ Да |
| ProductKey | `GG-XXXX-XXXX-XXXX-XXXX` | `LicenseOptions.ProductKey` в коде плагина | ❌ Нет (кроме `start-trial`, см. §3.1) |
| UpgradeCode | GUID | `PackageContents.xml` (обновления пакета) | ❌ Нет — это другой GUID |

Если подставить ProductKey (в командах кроме `start-trial`) или чужой/неверный GUID, ошибки не будет: панель откроется или активируется, но навигация на страницу продукта молча не произойдёт.

ProductId неизменен на всё время жизни продукта — вшейте его константой в код рядом с ProductKey.

**Где взять ProductId:** запросите его у поддержки платформы при создании продукта (в Developer Portal на вкладке «Общее» показываются API Key и UpgradeCode — это не ProductId).

### 3.1. Исключение: `start-trial` принимает и ProductKey

В отличие от `product`/`purchase`/`reviews`, команда `start-trial` понимает **оба** идентификатора в параметре:

```
grossgeo://start-trial/3fa85f64-5717-4562-b3fc-2c963f66afa6   # ProductId (GUID)
grossgeo://start-trial/GG-XXXX-XXXX-XXXX-XXXX                  # ProductKey
```

Если параметр не парсится как GUID, панель резолвит его как ProductKey сама (через каталог) — то есть можно использовать `LicenseOptions.ProductKey`, который у вас и так уже есть в коде плагина, не дожидаясь ProductId от поддержки. Рекомендуемый способ — SDK-метод `GrossGeoLicense.RequestTrialAsync()` (см. §4.1), он делает то же самое без ручной сборки URI.

`start-trial` **никогда не активирует лицензию тихо**: панель показывает то же диалоговое подтверждение, что и кнопка «Пробный период» на карточке продукта, и только если сервер разрешает trial для этого продукта/аккаунта. Если trial недоступен (уже использован, или продукт бесплатный) — просто откроется карточка продукта у блока покупки, без каких-либо действий.

## 4. Код

Один и тот же сниппет работает на `net48` (AutoCAD 2019–2024) и `net8.0-windows` (AutoCAD 2025+):

```csharp
using System;
using System.ComponentModel;
using System.Diagnostics;

public static class GrossGeoPages
{
    // ProductId вашего продукта в каталоге GrossGeo (не ProductKey!)
    private static readonly Guid ProductId = new Guid("3fa85f64-5717-4562-b3fc-2c963f66afa6");

    public static void OpenPurchasePage()
    {
        try
        {
            Process.Start(new ProcessStartInfo
            {
                FileName = $"grossgeo://purchase/{ProductId}",
                UseShellExecute = true   // обязательно: без этого URI-схемы не работают
            });
        }
        catch (Win32Exception)
        {
            // Схема не зарегистрирована — User Panel не установлен.
            // Предложите пользователю установить его: https://grossgeo.ru/download
        }
    }
}
```

`UseShellExecute = true` критичен: на .NET 8 значение по умолчанию — `false`, и запуск URI бросит исключение.

### 4.1. Альтернатива для trial: `GrossGeoLicense.RequestTrialAsync()` (SDK 2.1.6+)

Для кнопки «Попробовать бесплатно» проще использовать SDK-метод, а не собирать URI вручную — он использует `ProductKey`, который у вас уже есть в `LicenseOptions`, ходит через IPC вместо `Process.Start`, и сам запускает панель, если она ещё не открыта:

```csharp
[CommandMethod("MY_TRIAL_BUTTON")]
public async void OnTrialButtonClick()
{
    // Требует предварительного GrossGeoLicense.Initialize(...) с вашим ProductKey.
    await GrossGeoLicense.RequestTrialAsync();
}
```

Метод НЕ активирует лицензию сам — он только открывает панель на карточке продукта и просит её показать подтверждение старта trial (то же поведение, что у `grossgeo://start-trial/{ProductKey}`, см. §3.1). Требует **GrossGeo.SDK.Stub 2.1.6** или новее.

## 5. Поведение

| Состояние User Panel | Что произойдёт |
|---|---|
| Запущен (окно или фон/трей) | Окно активируется и перейдёт на нужную страницу |
| Установлен, но не запущен | Запустится и откроется сразу на нужной странице |
| Не установлен | `Process.Start` бросит `Win32Exception` — обработайте и предложите установку |

Если пользователь не авторизован в панели, сначала пройдёт обычный флоу входа, затем откроется запрошенная страница.

## 6. Типичные ошибки

1. **ProductKey вместо ProductId** — молчаливый no-op в командах кроме `start-trial`: панель откроется, но не на странице продукта (см. §3).
2. **UpgradeCode вместо ProductId** — оба GUID, но UpgradeCode каталогу неизвестен: навигация не сработает.
3. **Забыт `UseShellExecute = true`** — исключение при запуске на AutoCAD 2025+ (net8).
4. **Ожидание результата от `Process.Start`** — он не сообщит, найден ли продукт; корректность GUID проверяйте на своей стороне заранее.
